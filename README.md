# 🤖 ربات مدیریت کارهای روزانه (TaskBot)

دستیار شخصی کارهای روزانه روی تلگرام، با متن آزاد فارسی
بدون سرور شخصی • بدون دستور • کاملاً روی پلن رایگان Cloudflare

🌐 آدرس زنده: [https://lively-boat-43b8.zasnaashari81.workers.dev](https://lively-boat-43b8.zasnaashari81.workers.dev)

---

## ✨ این پروژه چیه؟
فقط عادی بنویس، خودش می‌فهمه:

| تو می‌نویسی | اتفاقی که می‌افته |
| :--- | :--- |
| «نان بخر» | کار جدید ثبت می‌شه |
| «نان رو خریدم» | تیک می‌خوره و از لیست انجام نشده‌ها حذف می‌شه |
| «کارام چیه» | لیست کارها رو نشون می‌ده |
| «همه رو پاک کن» | تمام کارها رو حذف می‌کنه |
| «سلام» | جواب conversational فارسی می‌ده |

هیچ دستوری (مثل /add) وجود نداره. فهمیدن پیام و تصمیم‌گیری کاملاً با هوش مصنوعیه.

## 🧠 اصل طراحی
مدل زبانی فقط یک خط JSON برمی‌گردونه و هیچ‌وقت مستقیم به دیتابیس دست نمی‌زنه. کد ما اون JSON رو اعتبارسنجی می‌کنه و فقط اگه معتبر بود، عمل می‌کنه. خروجی خراب ⇐ جواب امن «متوجه نشدم» و هیچ نوشتنی در دیتابیس.

## 🏗 معماری
- Webhook (نه polling): کد فقط وقتی پیام بیاد اجرا می‌شه؛ بدون مصرف بیهوده.
- Serverless / FaaS: بار کاری پراکنده و کوچیکه؛ نیازی به VM و Docker نیست.
- D1 (نه KV): داده‌ها رابطه‌ای هستن و به کوئری‌های WHERE و ORDER BY نیاز داریم.
- State: همه‌چیز توی D1؛ بین ری‌استارت‌ها ثابت می‌مونه.
- مدل زبانی: استفاده از Llama-3.3-70B در Workers AI برای دقت بالای فهم فارسی و JSON.

## 🔐 امنیت
- هر درخواست /webhook بدون هدر X-Telegram-Bot-Api-Secret-Token درست، **403** می‌گیره.
- فقط شناسه‌ی تلگرام مجاز پردازش می‌شه؛ بقیه بی‌صدا رد می‌شن.
- بعد از احراز هویت، همیشه **200** برمی‌گرده تا تلگرام پیام رو دوباره نفرسته.
- توکن بات و رمز webhook فقط توی secret store کلادفلرن؛ هیچ‌جای کد یا ریپو نیستن.
